\# E-commerse-sale-dashboard-



\# 📊 Ecommerce Sales Analytics Dashboard



This project was developed as part of my internship at CodeAlpha. The project focuses on extracting ecommerce product data from public web pages using Python web scraping techniques and visualizing insights through an interactive Power BI dashboard.



\---



\## 🚀 Project Overview



\* Extracted ecommerce product data using Python web scraping.

\* Created a custom dataset containing sales, profit, quantity, customer, and payment details.

\* Built an interactive dashboard in Microsoft Power BI for sales analysis and business insights.



\---



\## 🛠 Technologies Used



\* Python

\* Requests

\* BeautifulSoup

\* Pandas

\* Power BI



\---



\## 📌 Features



\* Web scraping using BeautifulSoup

\* Ecommerce sales dataset generation

\* Profit and sales analysis

\* State-wise and category-wise insights

\* Customer analysis

\* Payment method analysis

\* Interactive Power BI dashboard

\## 📂 Dataset Columns



\* Customer Name

\* Product Name

\* Category

\* Sub-Category

\* Amount

\* Profit

\* Quantity

\* State

\* Payment Method

\* Month



\---



\## 📈 Dashboard Insights



\* Gujarat, Madhya Pradesh, and Maharashtra are the top-performing states.

\* Electronics and Fashion categories contributed the highest sales quantity.

\* Tables generated the highest profit among sub-categories.

\* Most customers preferred UPI and Credit Card payments.

\* Sales and profit were highest during November and December.

\## ⚙️ Installation Process



\### Install Required Libraries



```bash

pip install requests beautifulsoup4 pandas

```



\---



\## ▶️ Run the Project



\### Step 1



Save the Python file as:



```bash

scraper.py

```



\### Step 2



Run the file:



```bash

python scraper.py

```



\### Step 3



CSV dataset will be generated:



```bash

ecommerce\_sales\_dataset.csv

```



\### Step 4



Open Power BI → Get Data → Text/CSV



\### Step 5



Import:



```bash

ecommerce\_sales\_dataset.csv

```



\### Step 6



Create dashboard visuals and KPIs.
