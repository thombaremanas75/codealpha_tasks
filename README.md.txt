## Task Completed

### IPL 2020–2025 Data Visualization Dashboard using Power BI

## Project Overview

This project focuses on analyzing IPL 2020–2025 batting and bowling datasets using Microsoft Power BI. The dashboard provides interactive visualizations and insights about player performances, trends, and statistics.

## Features

* Interactive Power BI Dashboard
* Top 10 Player Analysis
* Batting Performance Insights
* Bowling Performance Insights
* Dynamic Charts and Filters
* Cricket-themed Dashboard Design

## Tools & Technologies Used

* Microsoft Power BI
* Excel / CSV Dataset
* Data Cleaning
* Data Visualization Techniques

## Key Insights

* Most consistent run scorers across seasons
* Strike rate and batting comparison
* Top wicket-takers analysis
* Bowling economy trends
* Season-wise player performance visualization
